# PDF-источники и предпросмотр

Общий сценарий, правила биографии и численности собраны в [руководстве по LLM-модулю](LLM_WORKFLOW.md).

## PDF и предпросмотр

При обновлении через `POST /api/v1/ai/cards/{card_id}/refresh` поле `pdf_sources` принимает список `{url, pages}`. Источники должны относиться к официальному домену карточки. Поддерживается до двух PDF, до 20 страниц на источник, нумерация с 1. Без списка обрабатываются первые 20 страниц. Ограничение документа — 300 страниц, размер загрузки регулирует парсер.

Парсер извлекает текстовый слой и сохраняет номер страницы, хеш PDF, текстовый хеш и смещения цитаты. Связь числа со строкой и заголовком таблицы проверяет сотрудник. Для сканов нужен OCR. Защищённые PDF и страницы без текста отмечаются в диагностике.

`GET /api/v1/ai/runs/{run_id}/preview?expected_revision=N` создаёт отдельный PPTX для просмотра кандидатов. В отчёте отмечен статус кандидатов, а ссылки на цитаты из PDF открывают соответствующие страницы. Для итогового экспорта требуется принятая карточка.
