# Шаблоны презентации

Основной шаблон Демо 1 — `customer-card.json`, версия `customer-card-v1`.
Оформление и структура основаны на примерах ИКЭСТ/ИРНИТУ заказчика с улучшениями:
читаемый текст, отдельные источники, отсутствие пустых неподтверждённых показателей.
Это рабочая адаптация примеров, не заявление о согласованном корпоративном стандарте.

Секции задаются списком `sections`: `overview`, `leadership`, `biography`, `questions`,
`theses`, `sources`. Их можно переставлять/отключать без изменения LLM-контрактов.
Пустые разделы пропускаются; длинный текст переносится на дополнительные слайды,
без молчаливого обрезания. Точное наполнение можно изменить после согласования структуры.

Фото руководителей, логотипы учреждений, численность и показатели из примеров не
копируются. Они не становятся данными другого вуза. Основной шаблон заполняется
снимком принятых фактов, сохранённым вместе с материалом; модель не переписывает
должности, контакты и биографические значения при вёрстке. Вопросы/контекстные тезисы
берутся из черновика LLM со ссылками. Результат остаётся черновиком до проверки текста.

`assets/sber-logo.png` и два градиента извлечены без изменения из макетов
`Карточка_ИКЭСТ_2025.pptx`, предоставленного заказчиком. Логотип сохраняет пропорции.
Данные, фотографии и логотипы ИКЭСТ из слайдов не используются. `sber-gradient-cover.jpg`
сохранён для возможного отдельного титульного слайда; основной шаблон использует
только `sber-gradient-header.jpg`.

`meeting.json` / `meeting-v1` — первоначальный универсальный текстовый вариант;
остаётся резервом для старых вызовов генератора, не передающих структурированные факты.
HTTP-сценарий Демо 1 использует `customer-card-v1` и неизменяемый снимок выбранных фактов.
