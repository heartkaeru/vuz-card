## Как читать цифры

| Показатель | Как его понимать |
| --- | --- |
| Прошло тестов | Количество успешных автоматических тестов кода на указанной версии. Сборка frontend отражает отдельную техническую проверку. |
| Кандидаты | Записи, созданные при извлечении. В том же прогоне могут быть ошибки загрузки или таймауты. |
| Прошло автоматическую проверку | Сервер проверил структуру, цитату, ссылку и правила поля. Факт ждёт решения сотрудника. |
| Принято сотрудником | Запись вошла в действующую карточку после явного решения. |
| Подтверждено повторным сбором | Число ранее принятых фактов, для которых найдено то же значение с тем же владельцем, подразделением и контекстом показателя по свежему снимку ранее проверенного официального URL. Критерий относится к уже принятому факту. Дата проверки обновляется по времени получения доказательства, исходное решение сотрудника сохраняется. |
| Precision / Recall | Precision показывает долю правильных среди извлечённых, Recall — долю найденных среди эталонных. Для обеих метрик нужны эталон, область и размер выборки. |

### Как рассказать на встрече

**Контрольный замер от 15.11.** На трёх новых официальных страницах одного вуза и двух колледжей разметили 48 фактов. После автоматической проверки нашли 35 совпадений, один ошибочный факт и 13 пропусков. Precision составила 97,2%, Recall — 72,9%. По группам доля найденного составила 10/13 для ФИО, 7/13 для должностей, 9/13 для телефонов и 9/9 для почты. Общая почта одного колледжа прошла проверку с ошибочной привязкой к директору. Принятие сотрудником в этом замере не выполнялось. [Контрольный замер](../backend/reports/leadership_contacts_control_2026-11-15.md)

> После перехода на ID фрагментов мы нашли 15 из 15 размеченных ФИО и должностей на отладочной выборке. До изменения находили 9 из 15. На двух новых доступных страницах получили 18 из 18 в той же группе. На БГУ отдельно показали весь путь до презентации по 20 фактам, которые принял сотрудник.

Для следующего замера качества нужен более широкий набор вузов и СПО и второй разметчик. Для оценки экономии времени нужен отдельный замер подготовки к встрече вручную и через CRM на сопоставимых карточках.
