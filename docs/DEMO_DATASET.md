# Тестовый датасет для демонстрации

Набор для защиты: готовые карточки, которые открываются мгновенно, и список вузов для
быстрого парсинга, если нужно показать сам процесс.

Каталог: `backend/data/demo/`.

---

## Что внутри

| Файл | Что это |
|---|---|
| `registry.sqlite3` | Готовая база с 3 карточками и извлечёнными фактами |
| `universities.csv` | 10 вузов (название, короткое имя, город, сайт) для парсера |
| `expected.json` | Ожидаемые цифры по каждой карточке — с чем сверять экран |

### Содержимое базы

| Карточка | Сайт | Статус | Фактов | На проверке | Отклонено | Время сбора |
|---|---|---|---|---|---|---|
| урфу | https://urfu.ru | частичный | 451 | 451 | 0 | 556 с |
| Юургу | https://www.susu.ru/ | частичный | 163 | 146 | 17 | 431 с |
| Московский государственный университет | https://msu.ru/ | частичный | 19 | 19 | 0 | 119 с |

Для показа лучше всего **Юургу**: есть и должности, и контакты, и работа автопроверки
(17 отклонённых).

## Как запустить демо

Из каталога `backend`:

```powershell
$env:VUZ_MVP_DB = "data/demo/registry.sqlite3"
python run.py
```

Всё остальное как обычно: `python run.py` поднимает API на 8000, фронтенд — `pnpm dev` на 3000.

Карточки появятся сразу, без запуска сбора. Ничего парсить в зале не нужно.

> Если запускаете через ярлык/скрипт — переменную `VUZ_MVP_DB` нужно выставлять в том же
> процессе, где стартует `run.py`.

## Быстрый парсинг (если нужно показать процесс)

Список вузов — `backend/data/demo/universities.csv`. Парсер понимает CSV с колонками
`university, website`:

```powershell
cd backend
python -m parser.main --input-file data/demo/universities.csv --with-official-site --max-pages 1 --max-item-docs 0 --no-news-search
```

Один вуз (самый быстрый вариант, ~1–2 минуты):

```powershell
python -m parser.main --name "Казанский федеральный университет" --with-official-site --max-pages 1 --max-item-docs 0 --no-news-search
```

Ожидаемо: `Руководство: 218 | Контакты: 208 | Ошибки: 0`.

## Важно

1. **Не запускайте сбор в зале.** GigaChat ограничивает частоту запросов: несколько сборов
   подряд дают `invalid_context_json` и 0 фактов. Показывайте готовые карточки из базы.
2. Если всё же нужно запустить сбор — пауза 1–2 минуты после предыдущего.
3. Демо-база не меняет рабочую: она подключается только через `VUZ_MVP_DB`. Без переменной
   используется обычная `backend/output/mvp/registry.sqlite3`.
4. Вернуть обычный режим — просто перезапустить `python run.py` без переменной.
